Finding 3: Database Multi-Tenancy Unclear

⚠️ HIGH

Description: The SRS (Section 12.11) mandates row-level security and application-layer tenant scoping. The codebase has a tenant/ module but the depth of isolation enforcement is unclear.

Evidence:

Backend: ERP_Backend/src/main/java/com/cubeage/erp/tenant/ Tenant module exists but no TenantContext interceptor, RLS policy enforcement, or test cases for cross-tenant isolation found.

Recommendation: Conduct security audit:

  • Verify tenant_id is extracted from JWT and not client-supplied
  • Audit every query in every module to confirm tenant-scoping
  • Implement database-level RLS policies as backstop
  • Write integration tests attempting cross-tenant data access (should fail)

Finding 4: GST/Tax Compliance Incomplete

⚠️ HIGH

Description: Finance module has basic GL but GST calculation, validation, and report generation are incomplete—critical for India market launch.

Evidence:

Backend: ERP_Backend/src/main/java/com/cubeage/erp/finance/ (70 classes) No dedicated GSTCalculationService, GSTReportGenerator, or tax-configuration entity found. Frontend: No GST configuration panel or GSTR-1/3B export template visible.

Recommendation: Implement GST module:

  • Create GSTCalculationService with CGST/SGST/IGST rates per SKU
  • Implement GSTR-1 (outward supplies) and GSTR-3B (summary) report generators
  • Add GST configuration form in Finance module UI
  • Test against GSTN filing format

Finding 5: Approval Workflow Engine Incomplete

⚠️ HIGH

Description: FR-M1-05 requires a multi-level, configurable approval workflow engine. Current RBAC is functional but workflow state machine (templates, instance tracking, escalation) is not evident.

Evidence:

Backend: No WorkflowTemplate, WorkflowInstance, ApprovalStep entities found in admin/ or separate workflow package. Frontend: No workflow-configuration UI in tenantAdmin.

Recommendation: Build workflow engine:

  • WorkflowTemplate (name, steps[], conditions)
  • WorkflowInstance (template, currentStep, participants, timestamps)
  • ApprovalStep (order, role, action, deadline, escalation)
  • UI to define templates and monitor live instances
